### ⚡ Technical Highlights

* **DWM Material Integration:** Deep control over Windows 11 Desktop Window Manager (Mica, Mica Alt, Acrylic, and Custom Composition Materials).
* **Low-Overhead Telemetry:** Asynchronous hardware monitoring pipelines utilizing PDH and Direct3D query hooks for real-time tracking.
* **Workspace Management:** Direct multi-monitor workspace orchestration and dynamic display topology event listeners.
* **Modern Thread Pooling:** Optimized C++20 concurrent thread processing for background telemetry and system event loops.
* **Low-Level Abstractions:** Modular Win32 API wrappers for advanced power plan management, hardware state tracing, and virtual desktop switches.
